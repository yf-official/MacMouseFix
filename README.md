# Mac Mouse Fix Pro

这是一个原生 macOS 鼠标优化 App，目标是改善非 Apple 鼠标在 macOS 上的辅助按键和滚轮体验。

可直接运行的 App：

```text
dist/MacMouseFixPro.app
```

## 已实现功能

- 中文设置界面和中文菜单栏
- 菜单栏常驻 `MMF`
- 关闭设置窗口后，后台代理继续处理鼠标事件
- 菜单栏选择“退出并停止优化”会停止后台代理并恢复系统默认输入
- 主 App 通过 Command-Q、Dock 或系统退出时，也会停止后台代理
- 后台代理绑定主 App 进程，主 App 消失后会自动退出
- 通过 Core Graphics event tap 监听并改写全局鼠标输入
- 鼠标结构固定为：左键、滚轮、右键、辅助按键 1、辅助按键 2
- 左键和右键固定保持原样，避免误设导致鼠标不可用
- 可配置滚轮按下、辅助按键 1、辅助按键 2
- 默认映射：
  - 中键：调度中心
  - 辅助按键 1：后退
  - 辅助按键 2：前进
- 可选动作包括：
  - 后退 / 前进
  - 调度中心 / App Expose / 显示桌面 / 启动台
  - 切换左右桌面
  - 上一个/下一个标签页
  - 新建/关闭标签页
  - 刷新、复制、粘贴、撤销、重做
  - 放大、缩小、上一页、下一页
  - Esc、回车、区域截图、锁定屏幕
  - 中键点击、保持原样、禁用
- 滚轮优化：
  - 自然滚动方向切换
  - 滚动速度倍率
  - 触控板式丝滑滚动
  - 机械滚轮分段像素滚动
  - 拨轮停止后的短暂动量衰减
  - 触控板连续滚动保持系统原样，不参与鼠标滚轮算法
- 更小的设置窗口和可滚动内容区域
- 指针移动优化：
  - 鼠标指针平滑开关
  - 指针速度倍率
  - 小幅抖动低通平滑
  - 保留快速移动响应，避免明显拖拽延迟
  - 默认关闭，需要手动启用

## 首次使用

1. 打开 `dist/MacMouseFixPro.app`
2. 授权“辅助功能”
3. 如果没有自动弹窗，到：
   `系统设置 > 隐私与安全性 > 辅助功能`
4. 打开 `MacMouseFixPro`
5. 授权后 App 会自动启动后台代理
6. 可以关闭设置窗口，鼠标优化仍会继续生效
7. 如果要完全恢复系统默认输入，从菜单栏 `MMF` 选择“退出并停止优化”

## 重新构建

```sh
scripts/build_app.sh
```

## 当前限制

这已经是能实际影响鼠标输入的原生 App。关闭设置窗口后会通过后台代理继续生效；选择“退出并停止优化”会停止后台代理并恢复系统默认输入。Command-Q、Dock 退出或系统终止也会停止后台代理。指针平滑是轻量级事件位移修正，不是硬件级重采样；如果某些鼠标或触控板手感受影响，可以关闭“启用鼠标指针平滑”。暂未包含公证分发、登录项自动启动、按 App 独立配置档案、复杂拖拽手势和硬件级设备识别。
